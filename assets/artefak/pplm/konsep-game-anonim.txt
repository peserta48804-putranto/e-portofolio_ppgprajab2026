INFORMATIKA KELAS X
Gambaran Singkat Game
Game yang dibuat adalah Angry Birds versi GAMMA. Game ini berbentuk platformer 2D bertema action strategi. Pemain akan membantu karakter untuk menghancurkan pertahanan musuh. 
Game ini bisa dimainkan disemua kalangan usia dan bisa dimainkan didevice mobile, PC/laptop.
 Tujuan dan Peran Bermain
Pemain akan mengendalikan ketapel yang akan digunakan karakter untuk menghancurkan bangunan dengan cara mengontrol laju dan arah ketapel yang diinginkan serta pemain dapat menggunakan skill yang ada pada karakter untuk menyelesaikan stage.
Cara Bermain Utama
Pemain lebih sering mengontrol ketapel untuk menghancurkan pertahanan  musuh. Pemain bisa mengulang kembali proses bermain jika pemain mau. Lalu ada tombol skill karakter untuk mendapatkan kekuatan tambahan pada karakter. Pemain menarik karakter menggunakan ketapel. Semakin jauh tarikannya, maka semakin besar energi yang diberikan burung/karakter. Jika pemain gagal mengenai bangunan musuh, maka pemain akan mendapatkan sanksi berupa pertanyaan acak tentang matematika. Jika berhasil, maka pemain akan mendapat bonus 1 kali lembaran tambahan. Jika gagal menjawab, maka kesempatan lemparan akan dikurangi 1 kali. Pemain dianggap kalah jika lemparan habis. Sebaliknya jika seluruh bangunan hancur, maka pemain dianggap menang dan mendapat bintang. 
Aturan dan Tantangan
Aturan Permainan 
Pemain diharuskan menghancurkan bangunan musuh, jika gagal mengenai target, pemain akan dikasih pertanyaan acak tentang matematika dan jika berhasil menjawab, maka boleh lanjut dan mendapatkan 1 kali lemparan tambahan, sebaliknya jika pemain gagal menjawab pertanyaan maka kesempatan 1 kali lemparan dikurangi.
Tantangan permainan
Pemain akan dikasih pertanyaan acak tentang matematika dengan materi bebas. Entah materi SD, SMP, dan SMA/SMK. 
Alur dan Proses Permainan
Pemain dikasih 3 kali lemparan untuk menghancurkan bangunan musuh. Setiap lemparan, pemain bebas menggunakan skill yang ada pada karakter. Pemain bisa menggunakan tombol undo sebanyak 3 kali untuk mereset lemparan dan melempar kembali. Jika karakter mengenai bangunan musuh, maka pemainan berlanjut, tetapi, jika gagal mengenai , maka pemain mendapatkan pertanyaan acak tentang matematika dengan materi acak. Jika pemain berhasil menjawab pertanyaan, maka permainan dilanjutkan dan pemain akan mendapatkan lemparan tambahan 1 kali. Namun jika gagal menjawab pertanyaan, maka permainan berlanju dan kesempatan lemparan akan dikurangi 1. Pemain dianggap kalah apabila semua kesempatan melempar habis. Namun, jika pemain berhasil menghancurkan semua bangunan musuh, maka akan mendapat bintang dan kata-kata motivasi diakhir.
