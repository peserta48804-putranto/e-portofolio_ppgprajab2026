C.  Menyusun alur dan logika program
1. Ceritakan alur mekanik menggunakan kata-katamu sendiri.
Ketika ...              player menembak ke arah zombie
Program memeriksa ...   zombie terkena atau tidak oleh peluru
Jika ...                peluru  mengenai zombie
Maka ...                health zombie akan berkurang
Setelah itu ...         zombie akan mati
2. Tuliskan pseudocode sederhana sesuai alur di atas.
Pseudocode adalah urutan instruksi program yang ditulis dengan bahasa sederhana. Contoh kata kunci: WHEN, IF, THEN, SET, dan FOREVER.
Tanda “ ; “ berarti contiue, agar memudahkan dalam penulisan
Tanda “ { “ untuk memudahkan penggunaan FOREVER dan lainnya
IF user memencet tombol yang sudah ditentukan maka game akan dimulai.
SET healt player total 5.
Forever->{
IF user memencet tombol WASD maka akan bergerak ke arah yang di inginkan;
IF user menekan tombol tertentu maka akan menembak ke arah yang di tentukan;
IF user menyentuh zombie maka Health bar akan berkurang satu;
IF peluru mengenai zombie maka zombie akan mati karena health bar nya berkurang habis;
IF user menyentuh kotak/item yang ada pada map maka akan mendapatkan power boost sementara;
IF user health bar menyentuh nol maka akan game over dan Print(“GAME OVER”);
}
Gunakan IF, FOREVER, atau SET hanya jika dibutuhkan oleh mekanikmu.
